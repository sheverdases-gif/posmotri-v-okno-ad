# Проектная работа «Посмотри в окно»

Одностраничное приложение для просмотра видео из разных городов в разное время суток, созданное в рамках обучения на курсе «Фронтенд-разработчик» в Яндекс Практикуме.

## О проекте

В данной проектной работе основной задачей было написание CSS-стилей для уже работающего приложения. HTML-разметка и JavaScript-логика были предоставлены в готовой заготовке.

**Что реализовано:**

- Лейаут страницы с использованием Flexbox (выравнивание по центру, распределение колонок).
- Детальная стилизация всех компонентов интерфейса (тексты, кнопки, формы, карточки) в соответствии с макетом Figma.
- Стилизация интерактивных состояний (`:hover`, `:active`, `:focus-visible`).
- Кастомные чекбоксы (скрытие нативных элементов и отрисовка своих через псевдоэлементы).
- Обрезка переполняющегося текста в карточках (`text-overflow`, `line-clamp`).
- Подготовка контейнеров для корректного позиционирования прелоадеров загрузки.

## Технологии

- HTML5
- CSS3 (Flexbox, позиционирование, псевдоклассы, псевдоэлементы)
- Методология БЭМ
- Git / GitHub

## Как запустить

Проект не требует сборки. Достаточно клонировать репозиторий и открыть файл `index.html` в любом современном браузере.

**Важно:** Для корректной загрузки видео и карточек требуется работающий JavaScript и доступ к API.
